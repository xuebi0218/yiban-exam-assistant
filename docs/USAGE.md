# 使用说明

> 双击 `启动答题台.bat` 即可开始。浏览器打开 http://127.0.0.1:8765

---

## 一、开始之前

### 你需要准备的

1. **易班账号**（能登录 `www.yiban.cn`）
2. **考试资格**（课群里能看到考试，且有剩余重做次数）

### 你需要亲自做的两件事

| 事项 | 为什么必须人工 |
|---|---|
| **过人机验证** | 站点的数美/网易易盾验证码，技术上无法绕过 |
| **点交卷** | 不可逆操作，且会消耗一次重做机会 |

**其他全部自动。**

---

## 二、启动

双击 `启动答题台.bat`，浏览器会自动打开操作台。

界面分三栏：

```
┌────────────┬──────────────────┬──────────┐
│ 登录/配置   │   题目与答案      │  运行日志 │
│ 浏览器状态  │                  │          │
│ 流程按钮    │                  │          │
└────────────┴──────────────────┴──────────┘
```

---

## 三、登录（四选一）

### 方式 1：易班 Cookie 一键登录（推荐）

**最稳、免密码、免验证码。**

1. 浏览器打开 `https://www.yiban.cn/`，确认已登录
2. 按 `F12` → 点 `Console`
3. 输入 `document.cookie` 回车
4. 复制返回的那一整串（**注意：是 yiban.cn 的，不是 yooc.me 的**）
5. 回到操作台，点「**易班 Cookie 一键登录（推荐）**」
6. 粘贴 → 点「交换凭证并登录」

成功后会显示 `yiban_id`，并列出你能看到的考试。

> Cookie 有效期约 30 天，过期后重新复制一次即可。

### 方式 2：易班 App 扫码

点「**易班 App 扫码**」，二维码会直接显示在操作台里，用手机易班 App 扫。

二维码 60 秒过期，会自动刷新，不用管。

### 方式 3：账号密码

点「**账号密码登录**」，在弹窗里输账号密码，过人机验证。

### 方式 4：粘贴优课 Cookie（兜底）

如果 SSO 端点临时不可用，直接在 `www.yooc.me` 登录后复制 cookie 粘进来。
需要包含 `user_token / yiban_id / user_id` 三项。

### 检查登录是否真的有效

点「**检查登录状态**」。会真实查询业务接口，**不会骗你**。

## 四、答题流程

### 第 0 步：打开考试页

点「**⓪ 打开考试页**」，用系统浏览器打开考试列表，同时会告诉你：

```
考试状态:
  <examId>  已完成  得分=<score>  剩余重做=<n>
```

如果要重做，在那个页面里点「**重做试卷 → 开始考试**」。

### 第 1 步：拉取试卷

点「**① 拉取试卷**」。

- 会自动打开一个浏览器窗口（**只开这一个，后面都复用它**）
- 如果出现人机验证，**请在那个窗口里手动通过**
- 通过后自动拉题，日志会显示「答题页就绪 第 1/100 题」

### 第 2 步：生成答案

点「**② 生成答案**」。

中间栏会列出每题：题干、答案、来源徽章、置信度。

| 徽章 | 含义 | 要不要管 |
|---|---|---|
| 🟢 题库 | 历史真答案命中 | 不用管，100% 可信 |
| 🔵 教材·高置信 | 教材求解，置信≥0.90 | 不用管，实测 98.6% |
| 🟡 待复核 | 教材求解，置信 0.7~0.9 | 建议扫一眼 |
| 🔴 需人工 | 无可靠答案，**故意留空** | **需要你填** |

**设计原则：宁可留空，也绝不瞎填。** 填错直接扣分，空着还能补。

### 第 3 步：补人工题（如果有）

点中间栏的「需人工」筛选，逐题填写后点旁边的「存」。

填完可以再点「② 生成答案」重新统计。

### 第 4 步：填写到网页

点「**③ 填写到网页**」。

- **复用同一个浏览器**，不会再开新的，也不会再要求你过验证
- 自动按选项文字匹配填写（不是按字母，规避顺序错位）
- 完成后弹出：`空值 0 处` 表示全部填好

### 第 5 步：复核并交卷（人工）

浏览器窗口**不会自动关闭**，留在你手里。

1. 切到那个窗口（操作台点「**前置**」可直接提到前台）
2. 快速翻几页确认
3. **点「交卷」**

### 第 6 步：回捞

点「**④ 回捞（交卷后）**」。

会拉取本次真答案入库，题库自动增长，下次更准。

## 五、浏览器保活说明

操作台有一个「**浏览器（保活）**」卡片，显示：

```
● 运行中 · 03:42
http://exam.yooc.me/group/.../take
```

三个按钮 + 一个诊断：

| 按钮 | 作用 |
|---|---|
| **打开浏览器** | 打开并**自动导航到考试列表页**（不会停在空白页） |
| 前置 | 把窗口提到最前，方便交卷 |
| 关闭 | 交卷完成后手动关 |
| 查看页面（不操作） | 只读显示当前页面标题、地址、内容开头，**不会点击任何东西** |

**关键**：整个流程只用一个浏览器实例，所以人机验证**只需过一次**。

「打开浏览器」打开后会直接落在考试列表页，能看到「易班ID：xxx」
和「重做试卷，剩余N次」。如果显示的是登录页，说明 cookie 失效，重新登录即可。

## 六、常见问题

### 登录显示成功，但拉题说考试未进行

检查考试状态。`status=4` 表示已交卷，需要先去考试页点「重做试卷」。

### 提示「token 无效」

Cookie 过期了。重新去 `www.yiban.cn` 复制一次。

### 填写时又要求过人机验证

不应该出现。如果出现，说明浏览器被关了重开。请确认「浏览器（保活）」显示「运行中」。

### 有题目标红「需人工」怎么办

那是题库和教材都没找到可靠答案的题。你可以：
- 自己翻教材找答案填进去
- 或者留空（不扣分，只是拿不到那 1 分）

### 交卷后忘记点回捞

没关系，随时补点。同一个考试只需回捞一次。

### 服务打不开

确认 `启动答题台.bat` 窗口还在（关掉窗口服务就停了）。

## 七、一次完整操作（清单版）

```
1. 双击 启动答题台.bat
2. 粘贴 yiban.cn cookie → 交换凭证并登录
3. 检查登录状态           ← 确认有效
4. ⓪ 打开考试页 → 需要时点「重做试卷 → 开始考试」
5. ① 拉取试卷             ← 过人机验证
6. ② 生成答案
7. 补红色「需人工」题（如有）
8. ③ 填写到网页           ← 确认空值 0
9. 前置浏览器窗口 → 复核 → 点交卷
10. ④ 回捞
11. 关闭浏览器
```

---

## 八、注意

- **不要关掉服务窗口**，否则操作台失效
- **交卷前先复核**，交卷不可撤销
- 剩余重做次数有限，重做前想清楚
- 人机验证无法自动化，这是站点设计，不是工具缺陷
